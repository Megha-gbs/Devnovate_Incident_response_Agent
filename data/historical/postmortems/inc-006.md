# INC-006 — Notification service missing environment variable

## Summary
['Memory changes did not affect startup validation.', 'Retries could not help a process that never initialized.']

## Root Cause
The deployment omitted NOTIFICATION_PROVIDER_URL from the production environment.

## Successful Resolution
- Compared deployment environment with the previous release
- Restored NOTIFICATION_PROVIDER_URL
- Added startup configuration validation

## Failed Attempts
- Increased pod memory
- Deleted and recreated pods
- Changed retry count
