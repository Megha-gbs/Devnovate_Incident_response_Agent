# INC-016 — Auth gateway internal DNS outage

## Summary
['Scaling application pods did not repair DNS.', 'Retry increases added latency without fixing resolution.']

## Root Cause
A CoreDNS configuration rollout introduced an invalid upstream rule.

## Successful Resolution
- Checked DNS resolution from inside a pod
- Rolled back CoreDNS configuration
- Verified service discovery

## Failed Attempts
- Restarted auth pods
- Scaled auth gateway
- Changed application retry count
