# INC-021 — Kubernetes pod crash from invalid liveness probe

## Summary
['Resource changes did not affect the probe failure.', 'More replicas would have multiplied unnecessary restarts.']

## Root Cause
The deployment used the wrong liveness probe path after a route rename.

## Successful Resolution
- Compared probe path with application routes
- Corrected the liveness path
- Rolled out one pod first

## Failed Attempts
- Increased failure threshold
- Added more replicas
- Raised pod CPU limit
