# INC-008 — Auth gateway missing JWT issuer variable

## Summary
['Password rotation did not address token validation.', 'Restarting pods loaded the same incorrect value.']

## Root Cause
JWT_ISSUER was changed in the deployment template but the corresponding production value was not updated.

## Successful Resolution
- Compared current and previous deployment environment values
- Restored the correct issuer
- Added configuration drift detection

## Failed Attempts
- Rotated all user passwords
- Restarted gateway pods
- Increased token TTL
