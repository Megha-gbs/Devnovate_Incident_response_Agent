# INC-002 — Payments API database connection saturation

## Summary
['Horizontal scaling increased total connection pressure.', 'Database restart was avoided after rollback proved sufficient.']

## Root Cause
A deployment changed transaction handling and connections were not released on one error path.

## Successful Resolution
- Rolled back the deployment
- Verified connections were released after rollback
- Added connection leak test coverage

## Failed Attempts
- Scaled payments-api horizontally
- Restarted the database
- Raised request timeout
