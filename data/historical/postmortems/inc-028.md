# INC-028 — Reporting database replica lag

## Summary
['Application restart did not affect replica workload.', 'Timeout changes could not reduce replica lag.']

## Root Cause
A long-running analytical query on the read replica consumed resources and delayed replication.

## Successful Resolution
- Identified the long-running replica query
- Cancelled the offending query
- Added replica-lag alerting

## Failed Attempts
- Restarted reporting service
- Cleared application cache
- Increased report timeout
