# INC-004 — Reporting jobs consume all database connections

## Summary
['Scaling reporting workers increased DB connection usage.', 'Timeout increases only hid the underlying contention.']

## Root Cause
A new reporting job opened many concurrent database sessions and did not cap concurrency.

## Successful Resolution
- Capped reporting job concurrency at 5
- Killed only the runaway batch workers
- Added DB connection usage monitoring

## Failed Attempts
- Restarted reporting workers
- Increased web request timeout
- Scaled the reporting service
