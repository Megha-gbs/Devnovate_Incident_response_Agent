# INC-010 — Inventory API slow causes checkout timeouts

## Summary
['Checkout scaling did not reduce dependency latency.', 'Increasing the timeout delayed failures.']

## Root Cause
Inventory API experienced a slow query after a data growth threshold.

## Successful Resolution
- Confirmed inventory latency independently
- Applied the optimized inventory query
- Reduced checkout dependency timeout

## Failed Attempts
- Increased checkout timeout
- Restarted checkout
- Scaled checkout pods
