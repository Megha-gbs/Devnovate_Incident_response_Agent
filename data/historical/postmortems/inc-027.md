# INC-027 — Webhook duplicate delivery after retry change

## Summary
['Restarting workers did not change event identity.', 'Longer timeout did not address duplicate semantics.']

## Root Cause
Webhook retry policy was changed without preserving idempotency keys across retries.

## Successful Resolution
- Restored idempotency-key propagation
- Deduplicated queued events
- Added duplicate-delivery test

## Failed Attempts
- Disabled all webhooks
- Restarted workers
- Increased delivery timeout
