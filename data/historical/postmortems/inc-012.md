# INC-012 — User service memory leak after release

## Summary
['More memory only delayed OOM kills.', 'Redis clearing did not change heap growth.']

## Root Cause
A new profile serialization path retained large objects in memory.

## Successful Resolution
- Rolled back the release
- Verified memory stabilized
- Created heap profiling regression test

## Failed Attempts
- Increased pod memory limit
- Added more replicas
- Cleared Redis
