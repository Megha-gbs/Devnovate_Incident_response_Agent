# INC-001 — Checkout DB pool exhaustion during flash sale

## Summary
['Avoid blindly restarting pods; the symptom returned.', 'CPU scaling did not address the exhausted DB connections.']

## Root Cause
Connection pool size remained at 20 while traffic increased 3x during a flash sale.

## Successful Resolution
- Raised DB pool max to 60 after confirming DB had capacity
- Reduced connection leak by upgrading the DB client version
- Added pool utilization alert

## Failed Attempts
- Restarted checkout pods without changing pool configuration
- Increased application CPU limits
- Cleared Redis cache
