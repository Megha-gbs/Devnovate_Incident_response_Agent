# INC-025 — Third-party fraud API outage

## Summary
['Scaling did not repair the external provider.', 'Longer timeouts increased request backlog.']

## Root Cause
External fraud provider outage caused payment authorization requests to wait for downstream responses.

## Successful Resolution
- Confirmed provider 502s
- Enabled documented degraded-mode behavior for low-risk transactions
- Reduced retry amplification

## Failed Attempts
- Scaled payments-api
- Restarted payment pods
- Increased downstream timeout
