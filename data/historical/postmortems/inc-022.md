# INC-022 — Redis cache outage increases database load

## Summary
['Increasing DB pool could have worsened DB saturation.', 'Application restarts did not restore Redis.']

## Root Cause
A Redis cluster failover left several cache shards unavailable.

## Successful Resolution
- Confirmed Redis errors and cache miss increase
- Restored Redis shard availability
- Added cache degradation circuit behavior

## Failed Attempts
- Scaled checkout pods
- Increased DB connection pool
- Restarted checkout
