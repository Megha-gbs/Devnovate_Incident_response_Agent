# INC-026 — Search index corruption after node restart

## Summary
['Full cluster reindex was unnecessarily expensive.', 'Timeout changes did not repair the index.']

## Root Cause
A corrupted shard prevented normal index recovery.

## Successful Resolution
- Isolated the affected shard
- Restored the shard from snapshot
- Verified document counts

## Failed Attempts
- Reindexed the whole cluster
- Restarted all search nodes
- Increased query timeout
