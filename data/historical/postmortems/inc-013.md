# INC-013 — Search CPU spike from unbounded query

## Summary
['Scaling delayed saturation but did not remove the expensive query.', 'CPU limit changes only postponed the problem.']

## Root Cause
A newly enabled query allowed an expensive unbounded wildcard search.

## Successful Resolution
- Disabled the offending query pattern
- Added query cost limits
- Added CPU alert tied to query rate

## Failed Attempts
- Increased CPU limits
- Restarted search pods
- Scaled replicas
