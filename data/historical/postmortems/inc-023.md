# INC-023 — Payment API timeout from connection leak

## Summary
['Restarts were only temporary relief.', 'Longer timeouts increased resource retention.']

## Root Cause
A third-party HTTP client was not closing connections on failed requests.

## Successful Resolution
- Captured connection metrics
- Deployed client patch that closes failed connections
- Verified connection count stabilized

## Failed Attempts
- Restarted pods
- Increased timeout
- Scaled replicas
