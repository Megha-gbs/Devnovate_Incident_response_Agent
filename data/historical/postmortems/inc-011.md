# INC-011 — Notification provider outage

## Summary
['Credential rotation did not change provider 503s.', 'More workers increased retry pressure.']

## Root Cause
Third-party email provider had an external service outage.

## Successful Resolution
- Confirmed provider status and 503 response pattern
- Paused noncritical retries
- Resumed delivery after provider recovery

## Failed Attempts
- Restarted notification workers
- Rotated API credentials
- Increased worker replicas
