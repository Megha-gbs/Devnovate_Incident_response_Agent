# INC-024 — Bad deployment config disables inventory writes

## Summary
['Database capacity was healthy.', 'Restarting pods did not change the environment value.']

## Root Cause
A deployment config set INVENTORY_WRITE_ENABLED=false in production.

## Successful Resolution
- Compared environment configuration
- Restored INVENTORY_WRITE_ENABLED=true
- Added production config validation

## Failed Attempts
- Restarted inventory pods
- Cleared cache
- Increased database capacity
