# INC-003 — User service connection pool exhausted

## Summary
['Adding replicas did not solve the per-process pool limit.', 'Cache clearing had no effect on DB connection waits.']

## Root Cause
The service used a pool size of 10 after a configuration change, below the normal production value of 40.

## Successful Resolution
- Restored pool size to 40
- Confirmed pool wait time returned to baseline
- Added configuration validation at startup

## Failed Attempts
- Increased pod replicas
- Cleared application cache
- Restarted one pod
