# INC-005 — Checkout feature flag points to missing payment route

## Summary
['Pod restarts did not create the missing route.', 'CDN clearing was unrelated to the backend 404.']

## Root Cause
A feature flag enabled a new payment route before the route was deployed to production.

## Successful Resolution
- Disabled the feature flag
- Verified route availability
- Added flag-to-route deployment validation

## Failed Attempts
- Rolled back the entire application
- Cleared CDN cache
- Restarted checkout pods
