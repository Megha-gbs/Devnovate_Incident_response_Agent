# INC-015 — Payment DNS resolution failures

## Summary
['Application restarts could not fix resolver configuration.', 'HTTP timeout did not affect failed name resolution.']

## Root Cause
A DNS resolver configuration change introduced intermittent resolution failures for the payment provider domain.

## Successful Resolution
- Compared resolver configuration with baseline
- Reverted DNS configuration
- Added external DNS resolution checks

## Failed Attempts
- Restarted payment pods
- Rotated payment credentials
- Increased HTTP timeout
