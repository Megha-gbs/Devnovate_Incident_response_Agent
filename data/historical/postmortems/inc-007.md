# INC-007 — Search service wrong feature flag causes empty results

## Summary
['Full reindex was unnecessary.', 'Timeout tuning did not address the invalid alias.']

## Root Cause
A ranking experiment flag selected an index alias that did not exist in production.

## Successful Resolution
- Disabled the experiment flag
- Verified the index alias
- Added flag rollout checks

## Failed Attempts
- Reindexed the entire search cluster
- Restarted search pods
- Increased search timeout
