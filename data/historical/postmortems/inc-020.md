# INC-020 — Database migration blocks startup

## Summary
['Scaling created more blocked pods.', 'Startup timeout only prolonged rollout time.']

## Root Cause
A migration attempted to alter a large table synchronously during application startup.

## Successful Resolution
- Stopped the migration job
- Released the lock
- Ran the migration using an online procedure

## Failed Attempts
- Restarted failed pods
- Scaled the deployment
- Increased startup timeout
