# INC-030 — Authentication service unavailable after secret format change

## Summary
['Another rotation would reproduce the same incompatible format.', 'Restarting pods only reloaded the incompatible secret.']

## Root Cause
The signing secret was stored in a new encoded format but the application expected the previous representation.

## Successful Resolution
- Compared secret format between releases
- Restored compatible secret representation
- Added secret-format compatibility test

## Failed Attempts
- Rotated the secret again
- Restarted all pods
- Increased JWT tolerance
