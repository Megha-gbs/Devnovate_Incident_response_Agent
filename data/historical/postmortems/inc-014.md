# INC-014 — Reporting worker memory growth

## Summary
['More memory delayed failure.', 'Timeout changes did not reduce memory use.']

## Root Cause
A CSV export library retained generated rows until the whole job completed.

## Successful Resolution
- Changed export implementation to stream rows
- Restarted workers after deployment
- Added memory-per-job monitoring

## Failed Attempts
- Increased worker memory
- Reduced job timeout
- Added more workers
