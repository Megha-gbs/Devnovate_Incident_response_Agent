# INC-017 — Expired TLS certificate on payment provider

## Summary
['Restarting did not change certificate validity.', 'API key rotation was unrelated to TLS validation.']

## Root Cause
The client trust path encountered an expired provider certificate that had not been renewed.

## Successful Resolution
- Verified certificate expiry
- Escalated to provider and switched to the documented fallback endpoint
- Added certificate expiry monitoring

## Failed Attempts
- Restarted payment service
- Changed HTTP timeout
- Rotated API key
