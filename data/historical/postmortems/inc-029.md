# INC-029 — Checkout DNS failure caused by stale resolver cache

## Summary
['Application-level restarts did not clear the node resolver cache.', 'Timeout tuning did not affect DNS lookup.']

## Root Cause
A subset of nodes retained stale DNS resolver state after a service endpoint change.

## Successful Resolution
- Compared DNS resolution by node
- Flushed node resolver cache
- Verified consistent resolution

## Failed Attempts
- Restarted checkout application
- Scaled checkout pods
- Increased inventory timeout
