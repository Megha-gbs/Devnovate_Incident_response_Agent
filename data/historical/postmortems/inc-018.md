# INC-018 — Auth tokens rejected due to clock skew

## Summary
['Key rotation would not fix time-based validation.', 'Longer token lifetime would mask the infrastructure issue.']

## Root Cause
A subset of nodes had clock drift beyond the JWT tolerance window.

## Successful Resolution
- Compared node clocks
- Corrected NTP synchronization
- Verified token acceptance across nodes

## Failed Attempts
- Rotated signing keys
- Restarted all auth pods
- Increased token lifetime
