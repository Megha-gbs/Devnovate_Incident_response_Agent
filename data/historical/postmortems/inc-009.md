# INC-009 — Checkout payment provider timeout cascade

## Summary
['Scaling pods increased concurrent waiting requests.', 'Longer timeouts worsened request accumulation.']

## Root Cause
The external payment provider experienced elevated latency and checkout had an overly long upstream timeout.

## Successful Resolution
- Reduced provider timeout to 3 seconds
- Enabled graceful fallback for payment status
- Confirmed provider recovery

## Failed Attempts
- Scaled checkout pods
- Increased application timeout
- Restarted checkout pods
